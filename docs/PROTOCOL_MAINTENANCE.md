Khi debug, `_call_rpc()` log `RPC IDs in response: ...` sau parse `src/notebooklm_tools/core/base.py:1049`, `src/notebooklm_tools/core/base.py:1051`.
- Kiem tra/debug: chay CLI voi debug/log DEBUG de xem `RPC Call`, URL params, request params, raw response 2000 ky tu dau va danh sach RPC ID trong response `src/notebooklm_tools/core/base.py:1006`, `src/notebooklm_tools/core/base.py:1036`, `src/notebooklm_tools/core/base.py:1051`. ## Quy trinh cap nhat an toan

1. Tai hien loi bang command nho nhat va log DEBUG; luu raw response/request da redact neu parser/RPC thay doi.
2. Capture network request moi tu web app NotebookLM va doi chieu voi `docs/API_REFERENCE.md`; file nay da co endpoint/request format/RPC list nen chi cap nhat phan thay doi, khong viet lai toan bo `docs/API_REFERENCE.md:240`, `docs/API_REFERENCE.md:287`, `docs/API_REFERENCE.md:329`.
3. Sua tang thap nhat co lien quan: URL/body/parser trong `core/base.py`, token regex trong `core/auth.py` va `utils/cdp.py`, cookie freshness trong `core/cookie_rotation.py`, host allowlist trong `utils/config.py`/`utils/cdp.py`, hoac RPC constants trong `BaseClient`.
4. Neu chi RPC ID xoay, uu tien xac minh bang `NOTEBOOKLM_RPC_OVERRIDES` truoc; vi override ap dung luc client init, MCP server can restart de nhan env moi `src/notebooklm_tools/core/base.py:533`, `src/notebooklm_tools/core/base.py:576`.
